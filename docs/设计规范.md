# 设计规范

## 背屏

### 屏幕

| 项 | 值 |
|---|---|
| 分辨率 | 976 × 596 px |
| DPI | 450 |
| 左侧挖孔 | 296 px 宽，不放内容 |
| 内容安全区 | x ∈ [296, 976]，680 × 596 |
| 底色 | 纯黑 `#000000` |

### 面板布局

自研 `PanelView` 当前布局：

- 全屏黑底，覆盖原生时钟。
- 内容从 `x = 296 * scale` 开始。
- 中心：功率光环
  - 圆心：内容区水平中心，屏幕垂直中心
  - 半径：`min(680, h) * 0.33`
  - 轨道：`#33FFFFFF`
  - 进度弧：主题色
  - 液面：主题色 18% 透明
- 中心数字：功率 W，`sans-serif-light`
- 中心上方：“实时功率”
- 四角数据：
  - 左上：温度 `37.5℃`
  - 右上：电量 `64%`
  - 左下：电压 `4.48V`
  - 右下：电流 `1.80A`
- 顶部：状态胶囊（充电中/放电中/已充满/已连接）
- 底部：充电阶段 + 预计时间（快充 · 预计 42 分钟）
- 挖孔右侧边线：`#14FFFFFF` 1px

### 颜色

- 背景：`#000000`
- 主文字：`#FFFFFF`
- 次文字：`#B3FFFFFF` / `#8CFFFFFF`
- 主题色：`#38BDF8`（可配置）
- 充电阶段：超级快充 / 快充 / 涓流充电 / 充电中

### 动效

- 面板每 2 秒刷新。
- 进度弧/液面随电量变化。

**充电液体（2026-11-09 用户提示词，PanelView 与 App 预览同源参数）**

- 水面以下对背景做**逐水平条带位移重绘**：每条带按 `sin(y*k + t*w)` 计算水平偏移，幅度随深度**缓慢增大**（ramp = t^1.5，非线性），形成真实折射弯曲感。
- **不要用波纹贴图、不要画波浪线**来表现水；水体几乎不可见，只叠极淡吸收色（垂直渐变，最深处 alpha ≤ 0.30，背景透出）。
- 水面高光为**极细、断续、明暗不均**的短线（沿波面 ~56 段，随机长度/亮度，约 1/4 不画），不是连续亮边。
- 气泡**不填充**：只画边缘折射弧（STROKE 圆环）+ 左上高光点。
- 数据行与百分比数字保持原效果不动；禁止漫画风、描边、平涂色块。
- 参数集中在 `PanelView.java` 常量区与 `LiquidRefraction.kt` 的 `LiquidStyle`，两侧必须同步修改。

## App

### 底栏

5 个 tab：

1. 主页
2. 温控
3. 电池
4. 外观
5. 关于

### 主页

- 实时运行面板：能量光环、当前温控档位、实时数据格、容量/寿命、温区温度。
- 充电功率滑块：5W ~ 全速。
- 设备信息：模块版本、日期、型号、系统、运行环境。

### 温控

- 普通场景档位
- 充电场景：亮屏/息屏档位、定时切换
- 游戏场景：档位、刷新率、游戏应用列表
- 游戏加速：HyperOS 三倍速
- 自动任务：定时充电计划
- 旁路供电：手动/游戏/温度/电量阈值
- 高温保护备注

### 电池

- 电池解容（BAA/PSS）
- 公版 PPS
- 云控屏蔽
- APL
- DTBO（按钮暂为占位）
- 循环伪装
- 满电/关机电压

### 外观

- 8 套主题色：极光浅色、全息流体、暗黑霓虹、幻彩极光、赛博霓虹、熔岩鎏金、冰川琉璃、月海流银
- 玻璃材质/流畅模式
- 缩放/圆角/模糊/扭曲
- 底栏样式
- 背景/壁纸
- 背屏电池卡片预览

### 视觉规则

- 卡片圆角 ≤ 8px（现有 Glass 体系按其自身规范）。
- 不使用负字距。
- 数字使用 tabular-nums，避免跳动。
- 不使用纯装饰渐变球/光斑堆叠作为主视觉。
- 文本必须在容器内，移动端不得溢出。
- 工具型页面优先信息密度、扫描效率、可重复操作。
