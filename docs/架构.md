# 架构

## 目标

一个模块 + 一个 App，实现：

- 充电功率管理（引擎直接写 charger 节点）
- 动态温控（引擎应用 thermal 场景）
- 电池解容（BAA 挂载 + PSS）
- 背屏电池卡片（App 内 LSPosed hook + 自绘 PanelView）
- 数据获取（sysfs + BatteryManager）

## 引擎

### `engine/xjctl.sh`

App/脚本唯一入口。所有命令都在本进程内完成（`battery` 会 re-exec 到 PID1 namespace）。

主要命令见 [引擎API.md](引擎API.md)。

### `engine/xjdaemon.sh`

唯一常驻进程。每 `poll_interval`（默认 3 秒）执行：

1. `ensure_thermal_dir`
2. `hitemp_guard`
3. 禁用/关闭检查
4. `sample`（温度/电流/电压/电量/状态）
5. 前台应用/游戏识别（节流）
6. 旁路判定
7. `power_apply(effective_tier)`（非旁路）
8. 温控场景判定 + `apply_default` / `apply_conf_mode`
9. `battery_guard_tick`（无外部 battery 子系统时）
10. `rear_tick`
11. `write_status_json`

### `engine/lib/env.sh`

- `MODDIR` / `CONFDIR` / `CACHE` / `STATE` / `LOGDIR`
- `settings.json` 读写（平铺 JSON）
- `settings.conf` 读写（KEY=value）
- 功率档归一化（`inf/fast/mid/slow` + 自定义瓦数）
- 状态 JSON 片段拼装

### `engine/lib/data.sh`

- `find_ps` / `data_detect` / `data_read` / `data_sysinfo`
- 单位：`temp=0.1℃`、`current_now=µA`、`voltage_now=µV`、`charge_full=µAh`
- 双电芯：`cell_uv()` 优先 `voltage_avg/cell1_volt`，否则 `voltage_now/2`

### `engine/lib/power.sh`

- direct charger 节点：`wired_chg_curr`、`wired_ctrl_limit`、`wired_thermal_remove` 等
- `inf`：thermal_remove=1 + 恢复原电流
- 其它档：按目标瓦数换算电流，写入 ctrl/curr
- 节点已符合则跳过；同档位被驱动复位时按 `cg_min_write_gap`（默认 60s）节流
- 机型电流上限表：dada 12000 / miro 10250 / songyuan·pudding 9200 / warsaw·myron·annibale·popsicle 9000 / bixi 6500 / 其它 8000

### `engine/lib/thermal.sh`

- 探测 `mi_thermald` 等守护与 `/data/vendor/thermal/config`
- 原厂备份/还原
- `t_blank` / `thermal/N/thermal-scene.conf`
- `apply_default`：还原原厂配置 + 重启 thermal daemon
- `apply_bypass`：`t_bypass_0` + `set_charge_current(bypass_current)`
- `apply_conf_mode`：MD5 相同则跳过，切换后重启 thermal daemon

### `engine/lib/battery.sh`

新模块自己的解容核心（不调用旧脚本）：

- `dev_code()`：settings.conf 的 `dev_code` → vendor/odm/device prop
- `baa_src()`：`battery/baa/payload_BAA_config_<dev>.json`
- `baa_tgt()`：`/odm/etc/charger/BAA_config_<dev>.json`，找不到时扫描常见 charger 目录
- `baa_mount()`：`chcon` 复制目标 label → `mount -o bind` → SHA-256 回读校验
- `baa_umount()`：umount + `ctl.restart batteryantiaging`
- `pss_state/disable/enable`：`com.miui.powercenter.provider.PowerSaveService`
- `battery_boot/unlock_on/unlock_off`

**重要**：BAA 必须在 PID1 mount namespace 挂载；`xjctl.sh` 对 `battery` 命令用 `nsenter -t 1 -m` re-exec。

### `engine/lib/rear.sh`

- 目标 App：`com.hyperos.xj`
- APK：`app/HyperOS_XJ.apk`（单 App）
- 控制广播：`com.hyperos.xj/com.hyperos.xj.rear.ControlReceiver`
- 服务：`com.hyperos.xj/com.hyperos.xj.rear.RearService`
- 配置：外部 `Android/data/com.hyperos.xj/files/rear.conf` + `/data/local/tmp/xj_rear.conf`
- 不 `pm disable SubScreenLauncher`，不推 Display #1 任务

## App

### 模块

- `app/`：Compose Multiplatform 共享 UI + 页面 + RuntimeBridge
- `androidApp/`：Android 入口、LSP hook、RearService、BootReceiver、ControlReceiver
- `backdrop/`：玻璃/背景
- `xposed-stubs/`：仅编译用 Xposed API stub（`compileOnly`）

### 页面

- 主页：能量光环、实时数据、功率滑块、设备信息
- 温控：普通/充电/游戏/自动任务/旁路
- 电池：解容、PPS、云控、APL、循环、电压
- 外观：主题、玻璃、缩放、背景、背屏预览
- 关于：作者、版本、帮助、日志

### RuntimeBridge

- `readStatus()` → `sh xjctl.sh status` → 平铺 JSON → `DeviceStatus`
- `readThermalSettings()` → `sh xjctl.sh setting dump` → `ThermalSettings`
- `exec(command)` → `su -c <command>`（`Dispatchers.IO`）
- `Engine` 对象统一拼命令，页面不散落路径

### 单 App 内的背屏 LSP

- `assets/xposed_init` → `com.hyperos.xj.rear.RearHook`
- manifest：`xposedmodule` / `xposeddescription` / `xposedminversion=82` / `xposedscope=@array/xposed_scope`
- `xposed_scope` 只有 `com.xiaomi.subscreencenter`
- `RearHook` hook `SubScreenLauncher.onCreate/onNewIntent/onResume/onPause`
- `Overlay` 把 `PanelView` 加到 `decorView`，`onPause` 移除
- `Find` 用 `ActivityThread.mActivities` 找当前 `SubScreenLauncher`
- `RearService` 前台服务 + partial wakelock
- `ControlReceiver` 接收 `com.hyperos.xj.rear.CONTROL` 广播

## 配置与状态

| 文件 | 内容 |
|---|---|
| `config/settings.json` | 温控/游戏/旁路/计划/引擎开关 |
| `config/current_mode` | 当前已应用温控场景 |
| `config/status.json` | daemon 写的状态快照 |
| `config/runtime.json` | 热控探测结果 |
| `battery/config/settings.conf` | 电池/解容/功率/机型 |

## 生命周期

```text
刷入
  customize.sh
    ├─ 写 dev_code / mtk_fix
    ├─ seed config/settings.json
    └─ pm install com.hyperos.xj

开机
  post-fs-data.sh
    └─ 建目录 / seed settings
  service.sh
    ├─ 等 boot_completed
    ├─ engine/xjctl.sh battery boot（BAA/PSS）
    └─ engine/boot.sh（启动 xjdaemon + 看护）

运行
  App → xjctl.sh → 配置/节点
  xjdaemon → 温控/功率/背屏 tick/状态
  RearHook（subscreencenter 进程）→ PanelView overlay

卸载
  uninstall.sh
    ├─ rear off（恢复原生时钟）
    ├─ battery unlock off（BAA 卸载/PSS 恢复）
    ├─ power restore
    ├─ thermal set default + apply（恢复原厂）
    └─ 卸载 App / 清理模块目录
```
