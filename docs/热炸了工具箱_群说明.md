## 三、DTBO：哪些能刷、哪些不能刷

**能刷**
- 只有上表 15 个机型，且必须刷**本机代号对应的那个镜像**。
- 推荐流程：App → 电池页 → 「在线下载当前手机 DTBO」→ 页面会显示「自动识别：xxx.img（大小，来源）」→ 再点「刷入并重启生效」。
- 刷入前会自动备份到 `/sdcard/Download/dtbo_backup`，出问题可用备份还原。

**不能刷（会开不了机）**
- 表外机型：没有镜像，**不要**从别处找镜像凑。
- **跨机型刷**：哪怕同平台也不行（例如小米 15 和小米 15 Pro 都是 SM8750，但镜像不能混刷）。
- 网上的"通用 DTBO""解锁 DTBO"：一律不要。
- 分区节点找不到 / 不可写时，引擎会直接拒绝刷入 —— 这是保护，不要用别的工具强刷。

## 四、冲突说明（务必看）

| 同时装的东西 | 结论 | 原因 |
|---|---|---|
| **原版「电池解容工具箱」**（battery_tune 及各种二改版） | **冲突，只能二选一** | 两者都挂同一个 `/odm/etc/charger/BAA_config_<机型>.json`，并且都抢 `smart_fv`、`cyclecount`、PSS 组件、`pd_verifed` 这批节点；两边的守护进程会互相覆盖，表现为开关失灵、功率乱跳 |
| **只做解容的版本**（「仅解容」类模块/精简版） | **同样冲突** | 解容的本质就是「挂 BAA 载荷 + 写那批节点」，和它有没有温控功能无关；只要它也挂 BAA，就不能和本模块共存 |
| **单独安装的 FreePPS 模块** | **冲突** | 与本模块「公版 PPS 解锁」抢同一个 `pd_verifed` 验证节点，会互相拉锯（一个写 1 一个写 0）；本模块已内置该功能，不需要再装 |
| **其他温控 / 调度 / 锁频模块**（Scene 温控、各种 governor 调节、锁频、省电模块） | **不建议同开** | 都改同一批温控配置与频率策略，谁最后写谁生效，容易互相打架、功耗异常。要共存就只留一个主导，另一个设为「系统默认」或停用 |
| **LSPosed 模块** | **不冲突** | 背屏只 hook `subscreencenter`，与其他 LSP 模块作用域不重叠。安装后在 LSPosed 里勾选本模块作用域、勾选背屏相关系统应用即可 |
| **其他普通模块**（字体、音效、去广告、主题等） | 一般不冲突 | 只要不改 BAA 载荷、充电节点、温控配置就没事 |

> 简单记法：**凡是会"解容/改充电/改温控"的模块，都别和本模块同开；只改外观、音效、UI 的随便装。**

## 五、root 要求（重要）

必须**持久 root**：KernelSU / Magisk / APatch 正常安装，并且 **App 的 root 授权要选「永久允许」**。

| root 方式 | 能不能用 | 说明 |
|---|---|---|
| KernelSU / Magisk / APatch（持久 root） | **能用** | 模块由 root 管理器在开机时加载，App 需永久授权 |
| 授权弹窗选「临时允许 / 仅一次 / 10 分钟」 | **不能** | 授权过期后 App 全部开关失灵，后台守护也会被拒绝 |
| 临时 root（重启就失效的那种，含各类一键 root 工具） | **不能** | 重启后模块根本不加载，等于没装 |
| Shizuku / adb root / 无线调试 | **不能** | 只是 shell 权限，不能挂载 BAA、不能写充电节点、不能刷 DTBO |

为什么必须是持久 root：
- 解容要把 BAA 载荷 bind mount 到系统分区（PID1 mount namespace），shell 权限做不到；
- 温控 / 功率要常驻守护进程实时写 sysfs 节点；
- DTBO 刷写直接写块设备；
- 模块的 `post-fs-data.sh` / `service.sh` 只在开机时由 root 管理器执行。

## 六、注意事项

1. **解容会绕过原厂保护**：满压 4580mV、大电流充电，电池老化会加快，介意就别开。
2. **DTBO 刷入属高危操作**：刷错机型 = 开不了机。刷前确认「自动识别」显示的机型正确，并保留自动备份。
3. **卸载会自动还原**：BAA 卸载、smart_fv、循环次数、PPS 验证节点、充电节点、温控默认配置都会写回原厂值，不需要手动清理。
4. **升级直接覆盖安装即可**，升级后建议**重启一次**，让 BAA 载荷重新挂载。
5. **循环次数伪装**只影响显示，不修复电池健康度。
6. 关机电压、满压等参数是自行设置的，**风险自负**。
7. 出问题请用 App 里的「诊断包」反馈（可附最多 4 张图片），比口头描述好排查得多。
8. 90% 之后充电变慢是锂电池 CV 阶段 + 电池老化的正常现象，任何模块都无法完全消除。

## 七、安装步骤

1. Magisk / KernelSU 刷入模块 zip。
2. 安装 zip 内 `app/` 目录下的 App，授予 root 权限。
3. 打开 App → 首页确认设备信息与机型识别正确。
4. 电池页按需打开「电池解容」「公版 PPS 解锁」「云控屏蔽」。
5. 温控页选择档位（默认建议先「系统默认」观察）。
6. 背屏功能需要 LSPosed：启用模块并在作用域中勾选相关系统应用，重启后生效。
