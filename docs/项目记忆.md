# MiWKJR 项目记忆

## 2026-11-08 页面卡顿排查

- 根因一：Android `ToolboxRuntimeBridge.readStatus/exec` 虽为 suspend，但内部 `runAsRoot` 是阻塞式 `su -c`，在 Main 线程每秒轮询一次，周期性冻结 UI。已改用 `withContext(Dispatchers.IO)` 包裹。
- 根因二：玻璃效果按元素重复采样全屏背景，每个卡片/芯片/开关独立跑 `blur+lens+highlight+shadow+innerShadow` 并各自离屏合成，页面 40+ 个元素导致 GPU 过载，滚动时尤甚。
- 修复：`GlassCard` 去掉 `depthEffect/chromaticAberration` 与 `Highlight.Ambient/InnerShadow`；`GlassChip/ActionButton` 去掉高光；底栏隐藏克隆层改为纯色填充，移除一次完整模糊+折射通道。布局与功能未变。
- 验证：`:app:compileKotlinDesktop` 与 `:androidApp:assembleDebug` 均通过，APK 已刷新到 `动态温控解容工具箱_debug.apk`。真机帧率未测（adb 被沙箱拦截）。

## 2026-11-08 页面切换与卡片显示修复

- 页面切换去掉 `AnimatedContent` 淡入淡出与曲线，改为瞬时 `when(selectedTab)`；删除外观页"页面切换曲线/淡入淡出强度"两个控件与 `pageCurve/fadeStrength` 字段。
- 卡片圆角底色原来用全矩形 `drawRect` 填充，不随圆角变化，改为 `drawRoundRect` 并 cap 到 `size.minDimension/2`。
- 新增 `cardDistortion` 字段与外观页"卡片扭曲度"滑块（0..60），`GlassCard.lens` 的折射量改为读取该值。
- `LiquidGauge` 字号重复乘了屏幕密度（`gaugeSize.toPx()/176f` 再 `.sp`），手机上数字溢出光圈，改为 `(gaugeSize/176f).value`。
- 卡片模糊度默认改为 0（`AppearanceSettings.cardBlur = 0f`），`GlassCard` 与外观页滑块下限由 6 放开到 0。

## 2026-11-08 新架构与两次方向纠正

- 第一次错误：把 `source_snapshot/` 旧模块整体当底座，把新 App/新引擎贴上去。正确做法是新模块只保留自研引擎、单 App、必要数据（温控场景/BAA/DTBO），旧执行脚本和旧 UI 不进入新模块。
- 第二次错误：把背屏拆成独立 `com.hyperos.xj.rear` 第二个 App。正确做法是背屏 hook/服务/receiver 全部并入 `com.hyperos.xj`，模块只安装一个 APK。
- 最终架构：`com.hyperos.xj` = Compose UI + ToolboxRuntimeBridge + RearHook + RearService；`engine/` = xjctl + xjdaemon + lib/*；模块 = 新引擎 + 单 App + 数据资产。
- 背屏方案：hook `com.xiaomi.subscreencenter.SubScreenLauncher.onCreate/onNewIntent/onResume/onPause`，把 `PanelView` 叠加到 decorView，不禁原生时钟，不推 Display #1 任务。
- 解容方案：新 `engine/lib/battery.sh` 负责 BAA bind mount（PID1 nsenter）与 PSS；不调用旧 `battery/scripts`。
- 打包：v3.1.0 新模块，单 APK，`update-binary` 0755，所有 `.sh` 通过 `bash -n`。
