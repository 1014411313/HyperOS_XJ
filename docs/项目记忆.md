## 2026-11-20 USB 诊断电流与 APL 适配器指纹

- 依据诊断包 `2026-11-20T14-40-54-134Z`（模块/App 3.1.67）：用户报告未更换充电头，但 `battery.log` 出现 16 次「适配器变更」；采样 830 条充电流中 685 条 USB 电流为 0，无法还原充电头功率。
- 根因：`diag_log_tick` 只读 `usb/current_now`，该节点在充电时常常为 0；`apl_adp_fp` 把随充电状态变化的 `charger_common/power_max` 并入指纹，功率字段波动会被去抖后误判成换头并作废学习档案（该函数自身注释也写明功率会变）。
- 修复：`engine/lib/diag_log.sh` 新增 `diag_usb_read_current`，每拍读电流，`current_now` 为 0/无效时依次回退 `usb/input_current_now`、`qcom-battery/ibus_total`（mA→µA），电压与标称功率仍每 10 拍刷新；`engine/lib/apl.sh` 的 `apl_adp_fp` 只用 `usb/voltage_max`；`apl_adp_check` 对旧格式 `电压_功率` 且电压相同的档案就地迁移，保留已学习值。
- 变更：`engine/lib/{apl,diag_log}.sh` 及 `dist/HyperOS_XJ_New/engine/lib/` 同步副本、`scripts/charge_control_regression.py`、`scripts/selfcheck_regression.sh`。
- 验证：`sh scripts/selfcheck_regression.sh` 100 通过/0 失败（含 USB 回退与优先顺序）；`python3 scripts/charge_control_regression.py` PASS（含功率字段变化不触发换头、旧档案迁移）；两份 shell `bash -n`、`git diff --check`、engine/dist `cmp` 一致。模拟通过不代表真机验证：本机 `ibus_total` 快照为 0，需真机确认回退来源有非零值。
- 打包：`release_module.sh --local` 生成测试包 `dist/热炸了工具箱_v3.1.68_充电诊断USB修复测试_20261120.zip`（131 文件，sha256 `e6cac189…`）；原发布包已恢复为 `40c04eb6…`。测试包已在真机安装并重启生效（模块版本仍 3.1.68）。

## 2026-11-16 Xiaomi 15 Pro APL 降档重置与 dmesg 边界

- 用户授权修复诊断包 `2026-11-16T20-15-22-519Z` 对应的 APL 锁定绕过及硬故障日志读取问题；只在本地源码和回归沙箱修改，未安装、未刷机、未写真机节点。
- 根因证据：`apl_tick` 每拍先检查经过去抖的 USB 电压/充电器功率指纹；档案重置把目标重新设为电流上限。原代码在该判断前未加载 `apl_state`，因此塌陷 60 秒锁不能阻止重置抬高目标。诊断新段出现重复适配器重置与塌陷；采样同时显示降到 10000mA 后节点确有 10000000µA 回读，故不能说降档完全没生效，也不能据此认定全部波动根因已排除。

- 变更：`engine/lib/apl.sh`、同步副本 `dist/HyperOS_XJ_New/engine/lib/apl.sh`、`scripts/charge_control_regression.py`、`state/bugs.json` bug-136。

## 2026-11-08 页面卡顿排查

- 根因一：Android `ToolboxRuntimeBridge.readStatus/exec` 虽为 suspend，但内部 `runAsRoot` 是阻塞式 `su -c`，在 Main 线程每秒轮询一次，周期性冻结 UI。已改用 `withContext(Dispatchers.IO)` 包裹。
- 根因二：玻璃效果按元素重复采样全屏背景，每个卡片/芯片/开关独立跑 `blur+lens+highlight+shadow+innerShadow` 并各自离屏合成，页面 40+ 个元素导致 GPU 过载，滚动时尤甚。
- 修复：`GlassCard` 去掉 `depthEffect/chromaticAberration` 与 `Highlight.Ambient/InnerShadow`；`GlassChip/ActionButton` 去掉高光；底栏隐藏克隆层改为纯色填充，移除一次完整模糊+折射通道。布局与功能未变。
- 验证：`:app:compileKotlinDesktop` 与 `:androidApp:assembleDebug` 均通过，APK 已刷新到 `动态温控解容工具箱_debug.apk`。真机帧率未测（adb 被沙箱拦截）。
