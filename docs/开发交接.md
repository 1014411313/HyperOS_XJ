## 构建

```powershell
$env:GRADLE_USER_HOME = "D:\gradle"
cd ToolboxApp
.\gradlew.bat :androidApp:assembleDebug --offline
```

输出：

```text
ToolboxApp/androidApp/build/outputs/apk/debug/androidApp-debug.apk
```

复制到：

```text
dist/HyperOS_XJ_New/app/HyperOS_XJ.apk
```

## 打包模块

1. 确认 `dist/HyperOS_XJ_New/` 里没有旧脚本/旧 UI。
2. 确认只有一个 APK：`app/HyperOS_XJ.apk`。
3. 把根 `engine/` 同步到 `dist/HyperOS_XJ_New/engine/`（打包脚本会自动做）。
4. 跑 `bash -n`：

```bash
cd dist/HyperOS_XJ_New
find . -name '*.sh' -type f -exec sh -n {} \;
```

5. 打 zip（根目录必须是 `module.prop`）：

```bash
cd dist/HyperOS_XJ_New
zip -r ../HyperOS_XJ_新模块_v3.1.0.zip .
```

6. 确认 `META-INF/com/google/android/update-binary` 存在且 0755。

Windows 无 zip 时用 .NET `ZipFile` + `ExternalAttributes`，见 `docs/踩坑记录.md` 第 20 条。
